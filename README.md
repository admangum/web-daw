# Web DAW

A web-based digital audio workstation

## Why?

The goal of this project is to have fun with sound while learning about audio engineering and testing the limits of web browser performance.

## Quickstart

1. [Install pnpm](https://pnpm.io/installation)
2. Install project dependencies `pnpm install`
3. Run the dev server `pnpm dev`
